STEP 8 - Layout Structure with Navbar and Footer
To create a consistent layout across the entire application,

a global layout structure was implemented using the App Router.

File location:
src/app/layout.js

This file wraps all pages and provides shared UI elements.

Main responsibilities of the layout:
• Apply the ThemeProvider globally
• Inject GlobalStyle
• Render the Navbar component
• Render the Footer component
• Render page content between them

Code structure:
ThemeProvider wraps the whole application
GlobalStyle applies global CSS reset and base styles
Navbar appears at the top of every page
Footer appears at the bottom of every page
children represents the active route content
Result:

Every route automatically receives:
• Navbar
• Footer
• Global theme access
• Global styling

This eliminates the need to import layout components

inside each individual page.

STEP 11 - Featured Products Logic
The homepage includes a “featured products” section.

Instead of manually selecting products,

the logic filters products based on their tags.

Implementation example:
products.filter(product => product.tags.includes(“featured”))

This approach allows any product to become featured

simply by adding the tag “featured” inside the product data.

Advantages:
• No UI changes required
• Data-driven feature control
• Scalable for larger product catalogs

STEP 15 - Dynamic Product Detail Page
A dynamic route was implemented to display individual products.

Route structure:

src/app/products/[id]/page.js

The page uses the Next.js hook:

useParams()

Example:
const { id } = useParams()

The product is then retrieved from the product list:
products.find(p => p.id === parseInt(id))

If the product does not exist,

a fallback message is displayed.

This dynamic routing approach allows scalable URLs such as:
/products/1
/products/2
/products/3
